Getting Started

Built-in Loading Screen

The plugin has a ready-made loading screen, so you don't have to create a widget. It is used when Loading Screen Widget in Project Settings is empty. Set a widget there, or one in Map Overrides, to use your own instead.

The settings are under Built-in Loading Screen in Project Settings.

Layouts​

LayoutWhat is shown
ClassicLogo and title in the top left corner, with the tip, status, spinner and progress bar along the bottom.
CenterEverything centered on the screen.
LetterboxLogo and title in a band at the top, the rest in a band at the bottom.
SidebarEverything in a panel on the left side.
MinimalOnly the status and spinner in the bottom right corner.

Spinners​

SpinnerDescription
NoneNo spinner.
RingDots spinning in a circle.
ThrobberA row of pulsing pieces.
BlocksBouncing blocks.
BarsBars that grow and shrink.
ImageYour own Texture 2D, set in Spinner Image, rotating. Ring is used if the image is not set.

Color themes​

Choose Dark, Light, Cinematic or Midnight. With Custom you set the background, panel, text and accent colors yourself.

Content​

  • Title and Logo are optional.
  • The status text is Loading... by default. See Status Text for how to show what the game is doing, or your own text.
  • Tips come from Tips.
  • The progress bar and percentage are shown while something reports progress. Turn on Automatic Progress to get progress without code.
  • A slideshow replaces the background color.

The logo and spinner image must be included in your packaged build, in the same way as the images for the slideshow.
