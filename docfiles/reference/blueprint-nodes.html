Blueprint Nodes

Loading Screen Manager​

Get it with the Loading Screen Manager node, which is a Game Instance Subsystem getter. It doesn't exist on a dedicated server.

Functions​

NodeDescription
Get Loading Screen Display StatusTrue while the loading screen is shown.
Get Loading ProgressHow far the loading has come, from 0 to 1, or -1 if nothing reports progress. See Loading Progress.
Get Debug Reason for Showing or Hiding Loading ScreenWhy the loading screen is shown or hidden. See Displaying Reason.
Get Loading Screen Custom TextThe custom text as a string.
Get Loading Screen Custom Display TextThe custom text as a localizable text. Pure node.
Get Current Loading MapThe name of the map that is loading, or was loaded last.
Get Current Loading Screen TipThe tip to show. Pure node. See Tips.
Get Loading Screen Status TextThe text to show the player. Pure node. See Status Text.
Set Loading Screen TipsReplaces the tips while the game runs. See Changing tips and images.
Clear Loading Screen TipsGoes back to the tips from the settings.
Set Loading Screen ImagesReplaces the images from the next loading screen.
Clear Loading Screen ImagesGoes back to the images from the settings.
Is Waiting For Key PressTrue while the loading screen waits for a key press. Pure node. See Waiting for a key press.
Continue From Loading ScreenStops waiting for a key press.
Is Loading Screen Fading OutTrue while the widget fades out after the loading screen was hidden. Pure node. See Fading out.
Add Loading Screen WatcherAdds an object that is asked whether the loading screen should be shown. See Watchers.
Remove Loading Screen WatcherRemoves a watcher.
Set Loading Screen Custom TextSets a text that your widget can show. Takes a world context, so it can be called from anywhere without the manager.
Set Loading Screen Custom Display TextSame as Set Loading Screen Custom Text, but takes a localizable text.

Events​

Bind these on the Loading Screen Manager.

EventParameterDescription
On Loading Screen Visibility Changed DelegateNew StateThe loading screen was shown (true) or hidden (false).
On Show Loading Screen Additional Secs TriggeredIs ActiveThe extra hold time started (true), or the loading screen was hidden (false).
On Pre Load Map TriggeredMap NameA map started loading.
On Post Load Map TriggeredA map finished loading.
On Seamless Travel StartMap NameSeamless travel started.
On Loading Screen Tip ChangedTipA new tip was selected. See Tips.
On Loading Screen Status Text ChangedStatus TextThe status text changed.
On Waiting For Key Press ChangedIs WaitingThe loading screen started (true) or stopped (false) waiting for a key press.
On Loading Progress ChangedProgressThe loading progress changed. See Loading Progress.

Loading Process Task​

Shows the loading screen on demand. See Show on Demand.

NodeDescription
Create Loading Screen Process TaskCreates a task and shows the loading screen with the given reason. Returns the task. The advanced pins Timeout Seconds and Unregister With Context Object make the task stop by itself.
UnregisterRemoves the task, so it no longer keeps the loading screen up.
Set Show Loading Screen ReasonChanges the reason of the task.
Get Show Loading Screen ReasonThe reason of the task. Pure node.
Set ProgressReports how far the task has come, from 0 to 1. See Loading Progress.
Set Status TextSets a text to show the player. See Status Text.
Is ExpiredTrue when the task has timed out, or its context object is gone. Pure node.

Loading Process Interface​

Implement it on the Game State, a Player Controller, one of their components or a Watcher.

FunctionDescription
Should Show Loading ScreenReturn true to show the loading screen. Set Out Debug Reason to say why.
Get Loading ProgressReturn true and set Out Progress to a value from 0 to 1 to report progress. Return false to not be counted.
Get Loading Status TextReturn true and set Out Status Text to report a text to show the player.
