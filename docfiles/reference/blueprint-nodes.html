Blueprint Nodes

Loading Screen Manager​

Get it with the Loading Screen Manager node, which is a Game Instance Subsystem getter. It doesn't exist on a dedicated server.

Functions​

NodeDescription
Get Loading Screen Display StatusTrue while the loading screen is shown.
Get Debug Reason for Showing or Hiding Loading ScreenWhy the loading screen is shown or hidden. See Displaying Reason.
Get Loading Screen Custom TextThe text set with Set Loading Screen Custom Text.
Get Current Loading MapThe name of the map that is loading, or was loaded last.
Add Loading Screen WatcherAdds an object that is asked whether the loading screen should be shown. See Watchers.
Remove Loading Screen WatcherRemoves a watcher.
Set Loading Screen Custom TextSets a text that your widget can show. Takes a world context, so it can be called from anywhere without the manager.

Events​

Bind these on the Loading Screen Manager.

EventParameterDescription
On Loading Screen Visibility Changed DelegateNew StateThe loading screen was shown (true) or hidden (false).
On Show Loading Screen Additional Secs TriggeredIs ActiveThe extra hold time started (true), or the loading screen was hidden (false).
On Pre Load Map TriggeredMap NameA map started loading.
On Post Load Map TriggeredA map finished loading.
On Seamless Travel StartMap NameSeamless travel started.

Loading Process Task​

Shows the loading screen on demand. See Show on Demand.

NodeDescription
Create Loading Screen Process TaskCreates a task and shows the loading screen with the given reason. Returns the task.
UnregisterRemoves the task, so it no longer keeps the loading screen up.
Set Show Loading Screen ReasonChanges the reason of the task.

Loading Process Interface​

Implement it on the Game State, a Player Controller, one of their components or a Watcher.

FunctionDescription
Should Show Loading ScreenReturn true to show the loading screen. Set Out Debug Reason to say why.
