Settings and Console Variables

The settings are in Edit → Project Settings → Plugins → Common Loading Screen, and are saved to Config/DefaultGame.ini under [/Script/CommonLoadingSettings.CommonLoadingScreenSettings].

Loading Screen​

SettingDefaultDescription
Loading Screen WidgetNoneThe UMG widget shown as the loading screen. Leave it empty to use the built-in loading screen. A throbber is shown if the widget can't be loaded.
Z Order10000The Z order of the widget in the viewport. Keep it higher than your other widgets.
Automatic ProgressOffReports loading progress automatically when a map is loaded. See Automatic progress.

Timing​

SettingDefaultDescription
Additional Hold Time2.0Seconds to keep the loading screen up after loading has finished, so texture streaming can catch up.
Minimum Display Time0.0The shortest time the loading screen stays up once it is shown, so short loads don't flicker. 0 turns it off.
Fade In Duration0.0Seconds the widget fades in when the loading screen is shown. 0 shows it at once. See Fading in.
Fade Out Duration0.0Seconds the widget fades out when the loading screen is hidden. 0 removes it at once. See Fading out.
Wait For Key PressOffKeeps the loading screen up after a map has loaded until the player presses a key. See Waiting for a key press.

Status Text​

The text to show the player. See Status text. All texts except the default are empty, and an empty text uses Default Text.

SettingDefaultDescription
Default TextLoading...The status text when no other text applies.
Connecting TextEmptyShown while connecting to a server.
Loading Map TextEmptyShown while a map is loading.
Streaming Levels TextEmptyShown while streaming levels are loading.
Compiling Shaders TextEmptyShown while shaders are precompiling.
Finishing TextEmptyShown during Additional Hold Time and Minimum Display Time.
Key Press TextPress any key to continueShown while waiting for a key press.

Built-in Loading Screen​

Used when Loading Screen Widget is empty, and can only be edited then. See Built-in Loading Screen.

SettingDefaultDescription
LayoutClassicClassic, Center, Letterbox, Sidebar or Minimal.
TitleEmptyA title, for example the name of the game.
Show TipsOnShows the tips from Tips.
Show ProgressOnShows a progress bar and percentage while something reports progress.

Appearance​

SettingDefaultDescription
SpinnerRingNone, Ring, Throbber, Blocks, Bars or Image.
Spinner ImageNoneThe Texture 2D for the Image spinner.
LogoNoneA logo to show. Not shown with Minimal.
Logo Size128 x 128The size of the logo.
ThemeDarkDark, Light, Cinematic, Midnight or Custom.
Background, Panel, Text and Accent ColorBlack and whiteThe colors for the Custom theme.

Content​

Tips​

SettingDefaultDescription
TipsEmptyThe tips to show. See Tips.
Tip Duration6.0Seconds each tip is shown. 0 keeps the same tip until the next loading screen.
Shuffle TipsOnPicks the tips in random order instead of the order in the list.

Slideshow​

SettingDefaultDescription
ImagesEmptyImages to show behind the widget. See Slideshow.
Image Duration6.0Seconds each image is shown. 0 keeps the first image.
Crossfade Duration1.0Seconds the crossfade between two images takes.
Shuffle ImagesOffPicks the images in random order instead of the order in the list.

Music​

SettingDefaultDescription
MusicNoneThe sound to play while the loading screen is shown. See Music.
Music Volume1.0The volume of the music.
Music Fade In Duration1.0Seconds the music fades in.
Music Fade Out Duration1.0Seconds the music fades out when the loading screen is hidden.

Movies​

SettingDefaultDescription
MoviesEmptyThe movies to play while a map loads. See Adding movies.
Movie Playback TypeLooped Last PlaybackNormal Playback plays the movies once, Looped Playback loops all of them and Looped Last Playback loops the last one.
Movies Are SkippableOffThe player can skip the movies with a key or mouse click.
Wait For Movies To CompleteOffPlays the movies to the end. When off, they stop as soon as the map has loaded.
Show Widget Over MoviesOffDraws the Loading Screen Widget on top of the movies.
Use Movie Player During Load MapOffShows the widget with the Movie Player while a map loads, so it keeps animating. See Keeping the widget animated.

Adding movies​

  • Put the movie files in /Content/Movies in your project, for example Content/Movies/MyMovie.mp4.
  • Enter only the file name, without the path or extension. For Content/Movies/MyMovie.mp4 you enter MyMovie.
  • A movie that can't be found is skipped and a warning is logged.
  • Movies are not packaged as assets. Make sure they are copied to the packaged build: turn off Skip Movies and add the names to Movies that are not in UFS under Project Settings → Packaging. With Use Zen Store on, the movies end up in the pak file and the Movie Player can't open them.

Maps​

SettingDefaultDescription
Map OverridesEmptyDifferent content for specific maps. See Map Overrides.
Blocked Map NamesEmptyMaps that never show a loading screen when loaded or travelled to, also with seamless travel, for example MainMenu. Use the map's asset name, not the full path.
Blocked MapsEmptySame as Blocked Map Names, but you pick the maps from a list instead of typing their names. Both lists are used.

Map Overrides​

Use a different widget, movies, tips, images or music while a specific map loads. Add one entry per map.

FieldDescription
MapThe map the override is for.
WidgetThe widget to show while this map loads. Leave it empty to use the default Loading Screen Widget.
MoviesThe movies to play while this map loads. Leave it empty to use the default Movies.
TipsThe tips to show while this map loads. Leave it empty to use the default Tips.
ImagesThe images to show while this map loads. Leave it empty to use the default Images.
MusicThe music to play while this map loads. Leave it empty to use the default Music.

The override is picked when the loading screen is shown, from the map that is being loaded or travelled to. A loading screen that is already up when the load starts keeps its widget and images, but changes to the tips and music of the new map. The first loading screen when the game starts always uses the default widget.

Tips and images set from Blueprint or C++ take priority over Map Overrides. Durations, volume, fades and shuffling are shared by all maps. The splash screen always uses the default tips.

The images and music in all entries are loaded when the game starts and stay in memory, so showing the loading screen doesn't hitch.

Debugging​

SettingDefaultDescription
Log Reason Every FrameOffLogs the reason for the loading screen every frame.
Force VisibleOffAlways shows the loading screen.
Hold Time Even in EditorOnApplies Additional Hold Time in the editor too.

Console variables​

Four settings have a console variable, so you can change them at runtime. The Project Setting is the starting value.

Console variableSetting
CommonLoadingScreen.ShowLoadingScreenAdditionalSecsAdditional Hold Time
CommonLoadingScreen.ShowSplashScreenAdditionalSecsSplash Additional Hold Time
CommonLoadingScreen.LogLoadingScreenReasonEveryFrameLog Reason Every Frame
CommonLoadingScreen.AlwaysShowForce Visible

Command line​

ArgumentDescription
-NoLoadingScreenNever shows the loading screen. Not available in Shipping builds.

Upgrading from older versions​

Older versions saved the settings under [/Script/CommonLoadingScreen.CommonLoadingScreenSettings]. The plugin reads the old section on startup and copies values that are missing from the new section. It logs a warning when it copies anything. Move the values to the new section and remove the old one to get rid of the warning. When the new section already has every value, the old section is ignored and only a normal log line says that it can be removed.
