Settings and Console Variables

The settings are in Edit → Project Settings → Plugins → Common Loading Screen, and are saved to Config/DefaultGame.ini under [/Script/CommonLoadingSettings.CommonLoadingScreenSettings].

Display​

SettingDefaultDescription
Loading Screen WidgetNoneThe UMG widget shown as the loading screen. A throbber is shown if it can't be loaded.
Loading Screen ZOrder10000The Z order of the widget in the viewport. Keep it higher than your other widgets.
Splash Screen TypeBLACKThe splash screen on startup: BLACK, LOADING or IMAGE.

Configuration​

SettingDefaultDescription
Disable Splash Loading ScreenOffTurns off the splash screen.
Force Tick Loading Screen Even in EditorOnTicks Slate once when the loading screen is shown in the editor, so it is drawn right away.
Use Movie Player During Load MapOffShows the widget with the Movie Player while a map loads, so it keeps animating. See Keeping the widget animated.
Show Loading Screen Additional Secs2.0Seconds to keep the loading screen up after loading has finished, so texture streaming can catch up.
Show Splash Screen Additional Secs2.0Seconds to keep the splash screen up after the engine has finished loading.
Loading Screen Heartbeat Hang Duration0.0Seconds the loading screen can be up before the game is considered hung. 0 turns it off.
Log Loading Screen Heartbeat Interval5.0Seconds between each log of what is keeping the loading screen up. 0 turns it off.
Blocked Map NamesEmptyMaps that never show a loading screen when loaded or travelled to, also with seamless travel, for example MainMenu. Use the map's asset name, not the full path.

Splash Screen Configuration​

These settings are shown for the matching Splash Screen Type.

SettingTypeDefaultDescription
Splash Screen ImageIMAGEPlugin default imageThe Texture 2D to show.
Splash Screen StretchIMAGEScale To Fit XHow the image is scaled.
Splash Screen Stretch DirectionIMAGEBothWhether the image may be scaled up, down or both.
Splash Screen Loading TextLOADINGLOADING...The text to show.
Splash Screen Loading FontLOADINGRegular, size 10The font of the text.

Debugging​

SettingDefaultDescription
Log Loading Screen Reason Every FrameOffLogs the reason for the loading screen every frame.
Force Loading Screen VisibleOffAlways shows the loading screen.
Show Loading Screen Additional Secs Even in EditorOnApplies Show Loading Screen Additional Secs in the editor too.

Console variables​

Four settings have a console variable, so you can change them at runtime. The Project Setting is the starting value.

Console variableSetting
CommonLoadingScreen.ShowLoadingScreenAdditionalSecsShow Loading Screen Additional Secs
CommonLoadingScreen.ShowSplashScreenAdditionalSecsShow Splash Screen Additional Secs
CommonLoadingScreen.LogLoadingScreenReasonEveryFrameLog Loading Screen Reason Every Frame
CommonLoadingScreen.AlwaysShowForce Loading Screen Visible

Command line​

ArgumentDescription
-NoLoadingScreenNever shows the loading screen. Not available in Shipping builds.

Upgrading from older versions​

Older versions saved the settings under [/Script/CommonLoadingScreen.CommonLoadingScreenSettings]. The plugin reads the old section on startup, copies values that are missing from the new section, and logs a warning. Move the values to the new section and remove the old one to get rid of the warning.
